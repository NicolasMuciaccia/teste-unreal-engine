# Fotos de referência

Coloque aqui as fotos do anúncio, na **maior resolução disponível**.

Nomeie cada arquivo com o cômodo e um número, por exemplo:

```
sala-01.jpg
sala-02.jpg
cozinha-01.jpg
quarto1-01.jpg
banheiro-01.jpg
varanda-01.jpg
fachada-01.jpg
```

Se a mesma parede ou móvel aparece em mais de uma foto, melhor ainda: cada ângulo extra
ajuda a reconstruir as proporções.
